# Dataset Information

The data used in this project comes from **Kaggle**. 

## 📥 How to download the full dataset
Because the full dataset contains over 555,000 rows, it exceeds GitHub's file size limits (25MB). 

To download the full dataset used in this analysis:
1. Go to the official Kaggle page: **https://www.kaggle.com/datasets/kaggle/us-consumer-finance-complaints**
2. Download the .sqlite file.
3. Place the file inside this `/data` folder on your local machine.
